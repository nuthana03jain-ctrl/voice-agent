5 Cool Animations

Three text effects and two button effects, built with plain HTML, CSS and a little JavaScript.

Text · CSS only

1. Typewriter

Hello, animations!

How it works

The text starts with a width of 0 and overflow: hidden, so it's invisible. A @keyframes animation grows the width to full size.

The trick is steps(18): instead of growing smoothly, the width jumps in 18 steps, one per letter, so it looks like typing. A right border that blinks on and off is the cursor.

animation: typing 4s steps(18) infinite;
Text · CSS only

2. Gradient Shine

Shimmer

How it works

We paint a colorful gradient background that's much wider than the text (background-size: 200%).

background-clip: text cuts the background into the shape of the letters, and the text color is made transparent so the gradient shows through. The animation slides the background sideways, so the colors flow across the word.

background-clip: text;
animation: shine 3s linear infinite;
Text · CSS + JS

3. Wavy Letters

Wavy Text

How it works

CSS can't animate single letters, so a few lines of JavaScript wrap each letter in its own <span>.

Every span runs the same "jump up and back down" animation, but each one gets a slightly bigger animation-delay. Because they start at different moments, the letters move one after another like a wave.

span.style.animationDelay = (i * 0.1) + 's';
Button · CSS only

4. Fill-Up Button

How it works

The button has a hidden extra layer made with ::before (a pseudo-element). It's squashed to zero width with transform: scaleX(0).

On :hover we change it to scaleX(1). A transition makes that change glide over 0.4 seconds, so the color "pours" in from the left. The text color changes at the same time.

.btn-fill:hover::before { transform: scaleX(1); }
Button · CSS + JS

5. Ripple Click

How it works

When you click, JavaScript works out exactly where your mouse was inside the button and creates a small circle <span> there.

A CSS @keyframes animation grows the circle (scale) while fading it out (opacity). When the animation ends, JavaScript removes the circle so they don't pile up.

circle.style.left = (e.clientX - rect.left) + 'px';

Tip: if your device has "reduce motion" turned on, these animations slow down or stop. That's on purpose.
